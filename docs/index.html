IPPROTO

The one-byte Protocol field of every IP packet names what the packet carries. Here are all 256 values, from IANA's registry, in 13 categories. A capture file from tcpdump is read entirely in this page; nothing is uploaded.

All 256 numbers as a table

Open a capture file made with tcpdump or Wireshark (.pcap or .pcapng). The file is read in this page and never uploaded. To make one:

sudo tcpdump -i any -nn -w capture.pcap        # Ctrl+C to stop

            Busiest address pairs outermost header, by bytes

            A 1971 Teletype test stream cut into packets, each carried by an IP protocol number, saved as a .pcap file that tcpdump and Wireshark open. Packets are timed at the machine's speed: 10 characters a second for the Model 33, 15 for the Model 37.

            How each protocol is framed
            • Structured: TCP (6) to port 23, Telnet; UDP (17) and ICMP (1) echo; ICMPv6 (58) echo.
            • Tunnels around an inner UDP packet: IP-in-IP (4, 94), IPv6-in-IP (41), GRE (47), EtherIP (97), Ethernet (143), MPLS-in-IP (137).
            • Security: ESP (50) with SPI and sequence number; AH (51) followed by UDP.
            • IPv6 chains: Hop-by-Hop (0), Routing (43), Fragment (44), Destination Options (60) and Shim6 (140) followed by UDP; No Next Header (59); Mobility (135) and HIP (139) with no next header.
            • Every other number carries the teletype bytes directly after an IPv4 header. tcpdump may try to read those bytes as that protocol's header and report a bad checksum; that is expected.
            • Addresses come from the documentation ranges: 192.0.2.0/24, 198.51.100.0/24, 203.0.113.0/24, 2001:db8::/32. Timestamps start on 1 June 1971, 09:00 UTC.

            Each protocol number as a coloured SPAN, by an 8-bit extension of Gigaspeak's Calc28 scheme: bit 7 sets the foreground base to 55, as bit 3 does for the background. Numbers 0–127 have exactly Gigaspeak's colours; all 256 pairs are distinct. This extension is IPPROTO's own, not part of MDQNM.

            Data: IANA, Assigned Internet Protocol Numbers . The 13 categories are this site's grouping. Part of nth-member.
